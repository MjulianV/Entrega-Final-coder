# Taller 3D

Sitio estático de ejemplo para un taller de impresión 3D. Está hecho con HTML, SCSS, Bootstrap y AOS.

## Estructura
- `index.html`: inicio.
- `pages/`: servicios, trabajos, nosotros y contacto.
- `scss/`: estilos fuente divididos en partials.
- `styles/main.css`: CSS compilado.
- `assets/`: carpeta para agregar imágenes propias.

## Para abrirlo
Abrí la carpeta en Visual Studio Code y usá Live Server, o abrí `index.html` en el navegador.

## Para compilar SCSS
Instalá la extensión Live Sass Compiler en VS Code. Compilá `scss/main.scss` hacia `styles/main.css`. Si cambiás la ubicación de salida, asegurate de mantener el CSS dentro de `styles/`.

## Antes de entregar
1. Cambiá el nombre Taller 3D por el de tu emprendimiento si querés.
2. Reemplazá el correo de ejemplo y agregá tus datos reales.
3. Agregá tus propias imágenes en los espacios preparados para eso.
4. El formulario es visual y no envía mensajes todavía; para recibir consultas hay que conectarlo a un servicio.
5. Probá el sitio en celular y computadora.

## Publicación
Subí el proyecto a un repositorio público de GitHub y después importalo en Netlify o Vercel. Cuando esté publicado, pegá el enlace real del deploy en esta sección.
